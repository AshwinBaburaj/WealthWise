# WealthWise — Mutual Fund Investment Platform

A responsive web application for exploring and investing in mutual funds, featuring simulated real-time data, fund listings, investment tracking, and credit score evaluation.

## Features

- 🔐 User authentication (register/login/logout)
- 📊 Browse and explore mutual fund listings
- 💰 Simulated real-time fund data
- 📈 Investment tracking dashboard
- 💳 Credit score evaluation

## Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** SQL

## Getting Started

1. Clone or download this repository
2. Set up a local PHP server (e.g. XAMPP)
3. Import the database schema (`schemes.php` / `database.php`)
4. Run `index.php` on your local server

## About

Built as a mini-project exploring full-stack web development with PHP and SQL, focused on simulating a real-world fintech user flow — from registration to fund browsing to investment tracking.
